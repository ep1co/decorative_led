# decorative_led
Controlling leds with nucleo F401RE and receive command from terminal emulator.

This code controls 3 leds with a single push button, but can be expanded to more 
leds, more buttons, or using lcd external monitor instead of emulators like PuTTY,
terraterm,...

Before running the code, make sure to install a compatible IDE first (STM32CubeIDE
or Keil MDK-ARM is an ideal choice), then create an STM32 project using C language,
choose the right board and it's good to go.
